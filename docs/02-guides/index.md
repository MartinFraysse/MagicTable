# Guides

> Les tâches courantes, pas à pas : installer MagicTable, organiser un tournoi, suivre ses joueurs.

Les guides suivent l'ordre d'une première utilisation. Les libellés entre guillemets sont ceux de l'application.

La fenêtre se compose d'une barre de navigation à gauche et d'une vue par onglet :

| Onglet | Pour |
|---|---|
| 📊 Dashboard | le ou les tournois en cours |
| 🏆 Tournois | créer, inscrire, lancer, consulter l'historique |
| 👥 Joueurs | les joueurs réguliers |
| 👑 Commandants | les commandants et leurs statistiques |
| 📈 Stats | statistiques globales, classement, tête-à-tête |
| 🏅 Ligue | les ligues et leur classement cumulé |
| ⚙️ Paramètres | chrono, données, mise à jour |

En bas de la barre : « 🖥 Plein écran » et « ⏻ Quitter ».

| Page | Pour |
|---|---|
| [Installation](installation.md) | installer et lancer l'application |
| [Organiser un tournoi](organiser-un-tournoi.md) | de la création à l'archive, phase finale comprise |
| [Joueurs et statistiques](joueurs-et-statistiques.md) | joueurs réguliers, commandants, statistiques, ligues, paramètres |
