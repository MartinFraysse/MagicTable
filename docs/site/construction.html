Construction

L'état actuel de MagicTable : ses parties, comment elles communiquent, les fichiers qui comptent et les technos utilisées.

Vue d'ensemble

Les parties

Interface

src/ui/ : onglets Dashboard (rondes, tables, chrono, bracket, projection), Tournois, Joueurs, Stats, Ligue, Commandants, Paramètres.

Tournoi

core/tournament.py : joueurs, rondes, abandons, undo, sérialisation. create_round() choisit Swiss (1v1) ou tables 3-4 (Commander).

Swiss

core/swiss_pairing.py : couplage optimal (networkx). Priorités : pas de 2e bye, pas de revanche, bye au dernier, écarts de points minimaux, hasard.

Classements

core/standings.py (points, OMW%, GW%, OGW%), core/ranking.py (classement final, bracket prioritaire), core/bracket.py (Top 2/4/8).

Statistiques

core/stats_analyzer.py, core/commander_stats.py, core/league.py : calculées à partir des tournois archivés.

Stockage

src/storage/ : un JSON par ressource (tournois, joueurs, ligues, commandants) dans src/data/ ou %APPDATA%\MagicTable\data.
